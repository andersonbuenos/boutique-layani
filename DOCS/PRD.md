
# PRD — Boutique Layani

## 1. Visão do produto

Criar uma aplicação web de atendimento para a Boutique Layani,
uma loja fictícia de roupas.

O produto será um MVP (Produto Mínimo Viável) demonstrativo para uso educacional.

## 2. Problema

A boutique recebe perguntas repetidas sobre:
  Preços dos produtos
  Horário de funcionamento
  Taxa de entrega
  Disponibilidade e tamanhos

A equipe pode perder tempo respondendo repetidamente
às mesmas dúvidas.

## 3. Público-alvo

- Clientes da boutique
- Atendentes da loja

## 4. Objetivo

Permitir que clientes consultem informações básicas
por uma interface simples, rápida e acessível.

## 5. Dados oficiais do exemplo

Nome: Boutique Layani
Funcionamento: segunda a sábado, das 8h às 18h.

Produtos:
Camiseta: R$ 39,90
Calça jeans: R$ 119,90
Vestido: R$ 89,90

Taxa de entrega: R$ 10,00.

Estoque, tamanhos disponíveis, prazo de entrega e
políticas de troca não foram informados.

## 6. Funcionalidades obrigatórias

- Mostrar informações da boutique.
- Apresentar o catálogo de três produtos.
- Exibir uma interface de conversa.
- Responder perguntas sobre produtos e preços.
- Informar horário de funcionamento.
- Informar a taxa de entrega.
- Encaminhar perguntas desconhecidas a um atendente.
- Permitir limpar a conversa.
- Funcionar em celular e computador.

## 7. Regras de qualidade

- Não inventar preços ou disponibilidade.
- Não realizar vendas ou cobranças reais.
- Não coletar informações pessoais sensíveis.
- Utilizar dados fictícios.
- Ter interface responsiva e acessível.

## 8. Fora do escopo

- Integração real com WhatsApp.
- Pagamentos.
- Login.
- Cadastro real de clientes.
- Controle real de estoque.
- Backend e banco de dados remoto.
- Chamadas para modelos de IA na primeira versão.

## 9. Critérios de sucesso

A aplicação deve:
Exibir corretamente o catálogo.
Responder corretamente às perguntas conhecidas.
Encaminhar perguntas desconhecidas.
Funcionar em telas pequenas.
Executar localmente sem API paga.
